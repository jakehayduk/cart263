# Response to Project 1, Digi Chiika by Elle Lilin Kyuss Lim-Fauteux & Ash Oest O'Leary

Response by Jake Hayduk

[View their project online](https://mewmewpewpew.github.io/Project1/)


I really love the idea of the game, bringing back the tamagotchi style. The way that they used the animation that speeds up or slows down depending on if the pet is about to wake up by using the mouse hover is cool. Also the visual touch of having the bow and star on the chain dangle is nice. And it makes a sound when you click on them.

It would be nice if the game would save your pet and its attributes in localStoage so that your pet is still there when you open or reload the game. I can see that they began implementing something with localStorage that saves the names of the dead pets in the list, but I don't see the list showing up anywhere in the game or maybe I just can't find it. 

I like how the overall style and colour is unified. There is a clear aesthetic that works for this game. Maybe some more responsive features could be added to ensure consistency and balance in the design. 

In the HTML, on line 175, there is a space missing between the class and id attributes. Also the 'type' attribute doesn't go directly on audio elements, I'm pretty sure it's supposed to go on a nested source element if there is one. Don't forget to validate!

The CSS looks good but I would just say that it could probably be trimmed down a bit and formatted more consistently. The commented code is no longer needed and there are a few redundant declarations / more concise ways the layout could be written.

In the JS, same thing pretty much. The comments can be removed but it's definitely good to see the ones that are explaining what some of the functions to and whatnot. I like how everything seems to have their own named, separate functions and all the variables are defined at the top of the page, it helps with being able to read it.

I love the graphic pixel animation style that the pets have, I can see the effort that went into that and it fits the game perfectly. It's a great way to use GIF's as well. The color of the text in the input field could be more contrasting with the background, maybe white instead of black in this case. I feel like the icons are readable and make the game easy to understand which makes it good for all ages.

I think for sure the most surprising thing about the game are the things that happen when you max out your character's attribute levels. It would be very cool to see more interaction with those characteristics in the next version of the game and what happens after that. Just to have more distinctiveness between each created character besides just the name would be cool, because then you can how they are different to your friends.

Great job!
